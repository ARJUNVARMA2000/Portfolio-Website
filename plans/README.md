## Findings considered and rejected (do not re-audit)

- *Stale closure in chat keydown handler* — false: the effect lists
  `[open, onClose]` deps and re-binds correctly (`ask-terminal.tsx:100-107`).
- *Lenis not destroyed under reduced motion* — by design: no instance is ever
  created when `prefers-reduced-motion` matches (`smooth-scroll.tsx:31`).
- *TraceReplay run-switch race* — handlers null-guard `tlRef`, `onComplete`
  resets `playing`, `selectRun` resets state; behavior manually verified in
  the rebuild log (`tasks/todo.md` Phase 6).
- *Missing .env.example* — it exists and is accurate.
- *react-markdown bloats client bundle* — `components/case-study/article.tsx`
  is a server component; ReactMarkdown renders at build time and ships no JS.
  The 165 kB first-load on `/` is a documented accepted trade-off
  (`tasks/todo.md:58`).
- *Font `text` subsetting* — inapplicable: the chat renders arbitrary text;
  `next/font` already subsets latin and self-hosts.
- *Standalone ESLint 9 bump* — blocked by `eslint-config-next@14` (expects
  ESLint 8); belongs to a future Next 15 migration, not a quick win.
- *Defensive logging in multi-agent SVG selectors* — the SVG is hand-authored
  in the same file; guards against a malformed DOM that can't occur add noise.
- *Test suite for the site* — fully static content + one API route; cost
  exceeds value. CI build/typecheck/lint (Plan 003) is the right-sized gate.
